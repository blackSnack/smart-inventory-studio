# InvenTree Metadata read port (#10 #17)
The standalone GET-only adapter implements the existing MetadataReadPort and exposes a validated cabinet readback helper. The location model identifier is supplied explicitly; no default is guessed. GET schema declarations, exact location ID, current location tree, response envelope and layout binding are checked. Empty unmanaged metadata is distinct from denied, invalid or stale metadata. Unrelated metadata keys are preserved. No write methods or production PWA wiring are introduced.
 
Route convention follows the existing isolated migration transport and public API schema reference https://docs.inventree.org/en/latest/api/schema/general/. The exact 1.7.4 model identifier, permissions, response envelope and concurrency behavior remain runtime acceptance in #23. The schema alone does not establish that the configured model is correct. Tree and metadata reads are separate requests, not a transactional snapshot. Tests use an injected HTTPS fixture only.
