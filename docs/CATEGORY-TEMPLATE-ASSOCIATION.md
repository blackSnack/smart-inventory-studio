# Category template association preview (#6 #10)
Pure preview for an explicitly complete same-instance snapshot of categories, templates and direct relations. Uses existing exact semantic mapping approval (name/alias alone remains review). Direct association, ancestor evidence, proposed association, template creation and review are distinct. Ancestor relation is not proof of effective inheritance. Disabled templates cannot be recommended for association. No new operation protocol, write or automatic association. The caller must collect complete runtime evidence and verify inheritance, native field type and exact relation API before dispatch (#23); snapshot completeness is a caller assertion, not a transaction guarantee.

The standalone InvenTreeAssociationReader obtains the three existing GET collections with schema gating and validated pagination, joins exact IDs and validates the whole observed tree/relations. It returns `complete:false` deliberately: operator/local acceptance must confirm visibility and stable read window before using the preview. Native scalar templates remain `unknown` unless an explicit semantic review matches current enabled ID/name/unit; checkbox and choices remain their native type. A read does not authorize creation or prove inheritance. No production wiring, writes or real schema claim.
