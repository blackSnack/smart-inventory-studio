# InvenTree catalog read software contract (#10)
Standalone CatalogReadPort implementation using the existing bounded, scope-checked list transport and an explicit GET schema probe. Public API references: https://docs.inventree.org/en/latest/api/schema/part/, https://docs.inventree.org/en/latest/api/schema/company/, https://docs.inventree.org/en/latest/api/schema/general/. The version-specific 1.7.x endpoint pages were not retrieved; the latest public schema and synthetic fixtures are guidance, not verified 1.7.4 compatibility.
 
The adapter reads exact Part detail, scoped Part parameters, manufacturer and supplier records with company details, and attachment link metadata. It rejects mismatched record/company IDs, duplicate rows and invalid parameter scope. It preserves raw values, does not turn missing manufacturer/SKU data into an identity, and does not follow external URLs or download files. Only credential-free absolute HTTPS external links are retained. Attachment links are not certified as datasheets; private attachment files and relative media paths are omitted. Category relations are read directly, with exact category selection; inherited templates are not inferred. Native scalar type without an explicit checkbox/choice declaration is unknown, not assumed from units.
 
This adapter is not yet connected to the production PWA and does not advertise verified runtime capabilities or enable writes. Before integration, verify actual 1.7.4 schema, attachment model identifier, category inheritance, permissions, response envelopes, and source link policy in #23. Tests use only injected GET fixtures and the existing InventorySession boundary. No production credentials or data.
