# Isolated Part creation (#10 #27 #28)
Fixture-only .test transport for approved create-part. Public schema: https://docs.inventree.org/en/latest/api/schema/part/. Supports a new partial component only, with explicitly reviewed IPN, category identity and basic fields. No exact manufacturer/supplier identity, parameter/source or stock association is implied. IPN exact lookup, current nonstructural category and create response ID are checked; readback also requires no initial StockItem. Caller must have reviewed candidates; IPN uniqueness alone is not semantic identity or complete candidate coverage. Lost acknowledgement remains unknown and no automatic replay. Part creation and receipt are separate operations and require separately reviewed IDs; no production wiring, writes or real schema claim. Actual concurrency, IPN settings, defaults and permissions remain #23.
