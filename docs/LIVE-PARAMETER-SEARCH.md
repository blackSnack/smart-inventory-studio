# Native parameter search
Public schema reference: https://docs.inventree.org/en/stable/api/schema/general/ (parameter list and template list). The running instance is authoritative, not the documentation. Explicit probe reads OpenAPI declaration and actual template list before enabling native filters. Only part.part rows and enabled templates are accepted; IDs are not inferred from names. Exact text is default. Numeric comparison accepts nonnegative decimals in the template's unit or explicit SI values for supported base units; conditioned or unparseable values remain unknown. No reliance on floating-point data_numeric. This is native template filtering, not approval of a local-to-remote catalog mapping. Actual 1.7.4 runtime and legacy API variants remain #10/#23. No writes.
