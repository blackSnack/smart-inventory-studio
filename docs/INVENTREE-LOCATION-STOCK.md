# Location stock read (#10 #17)
Standalone GET-only reader, using existing schema and pagination checks. Public reference https://docs.inventree.org/en/latest/api/schema/stock/ documents the location and cascade filters. Exact leaf identity is verified against a fresh tree; request uses location and cascade=false, rejects other locations and duplicate stock IDs. Quantity is kept as a decimal string; unsafe fractional JSON numbers fail closed. Positive recorded quantity is not available/unallocated stock, and zero recorded quantity is not physical capacity or occupancy confirmation. Empty results are distinct from request errors. No production service access or writes; actual 1.7.4 filtering, completeness, quantities and permissions require #23. No UI change in this PR.
